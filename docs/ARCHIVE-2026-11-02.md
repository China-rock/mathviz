## 五、环境坑（再遇到别重复踩）

- **manim 子进程的工作目录不能含空格**：否则 MiKTeX 的 `dvisvgm` 报 `Windows API error 87`，
  看着像 TeX 坏了。所以渲染固定在 `%LOCALAPPDATA%\MathVizWork`。
- 本机 `USERNAME` 环境变量是 `67676`，但用户目录是 `C:\Users\ChRis`，别用 `%USERNAME%` 拼路径。
- PyPI 直连 ~60 KB/s，装包一律加清华镜像；uv 同时只能跑一个进程。
- GUI 测试组会弹窗，`run_all_tests.py` 必须串行；与冒烟测试并行会互抢窗口导致误报。
